## Политика конфиденциальности VSMGram
#### Действует с 16 мая 2023 года

Настоящая политика конфиденциальности описывает, какие данные собирает и обрабатывает VSMGram — неофициальный клиент Telegram для Android.

## Открытый исходный код
VSMGram распространяется с открытым исходным кодом в соответствии с требованиями Telegram API и лицензии GNU GPL. Код доступен на [GitHub](https://github.com/exteraSquad/VSMGram).

## Сбор и использование данных
Я серьёзно отношусь к вашей приватности. VSMGram собирает минимально необходимые данные исключительно для обеспечения работы приложения и устранения ошибок:

1. **Технические логи**: При использовании приложения автоматически собирается техническая информация — модель устройства, версия ОС, версия приложения, отчёты об ошибках. IP-адрес не собирается. Логи используются только для диагностики и исправления неполадок.

2. **Публичный контент**: Всё, что вы публикуете в открытых чатах и каналах, доступно другим пользователям Telegram. Публикация запрещённого контента (спам, фишинг, оскорбления) может повлечь блокировку аккаунта со стороны Telegram.

3. **Контакты и геолокация**: Приложение может запрашивать доступ к контактам (для отображения имён в уведомлениях) и геолокации (для функции «Поделиться местоположением» или «Сделать меня видимым для людей рядом»). Управление этими разрешениями — в настройках приложения: Настройки → Конфиденциальность → Настройки данных.

## Сторонние сервисы
Для корректной работы приложения используются следующие сторонние сервисы:

1. [Google Play Services](https://play.google.com/store/apps/details?id=com.google.android.gms) — системные сервисы Android, сбор данных регулируется политикой Google.

2. [Firebase Notifications](https://firebase.google.com/) — доставка push-уведомлений от Telegram. Для этого с Firebase может передаваться токен устройства.

3. [Crashlytics](https://firebase.google.com/products/crashlytics) — сбор отчётов об ошибках и сбоях для повышения стабильности приложения.

4. [Google Analytics](https://firebase.google.com/products/analytics) — анонимная аналитика использования приложения для улучшения пользовательского опыта.
